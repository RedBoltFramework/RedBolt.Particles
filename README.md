# RedBolt.Particles

Optional programmable particle graphs and emitters for [RedBolt](https://github.com/RedBoltFramework/RedBolt).

The source build expects RedBolt in `../RedBolt` by default. Override `RedBoltRoot` when the repositories use a different layout.

```sh
dotnet build RedBolt.Particles.slnx --configuration Debug
```

Desktop, WebAssembly, and Android versions of the Particles sample are included under `src/RedBolt/Sample`. Tests remain in the sibling `RedBolt.Tests` repository.
